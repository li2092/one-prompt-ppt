# 第 3 层 页：标题、导语和内容块

这一层定每页的标题（`title`）、有哪几个内容块（`blocks`），以及按需要写的导语（`lead`）、结论条（`conclusion`）和讲述要点（`notes`）。每页放哪些内容、摆成什么样，先按 `page-plan.md` 规划；内容块内部怎么做见 `L4-block.md`。

## 一、页面的四个位置

一页回答一个问题。四个位置各说各的，不互相重复。

| 位置 | 说什么 | 常见错误 |
|---|---|---|
| 标题 | 这页的论点或主题 | 写成口号；超过两行 |
| 导语（按需要） | 主题式标题下的论点、数据口径，或告诉听众怎么读下面的图 | 把标题换个说法再说一遍；写成标签；每页都写 |
| 主体 | 支撑论点的证据，以图示为主 | 把所有相关材料都放上来 |
| 结论条（按需要） | 这页内容推出的、标题里没有的一句话：下一步的动作，或对听众的请求 | 重复标题；每页都硬加一条 |

单页的“总分总”就落在这里：标题概括，主体展开，需要时用结论条收束。标题已经是一句完整论断的页不写导语；主体已经把话说完的页不写结论条。同一件事一页只说一次。

一页出现两个论点时拆成两页。

## 二、标题

三种写法：

- 主题式：名词短语，点明这页讲什么。例：“合同管理系统的设计原则”。
- 论断式：一句完整的判断，读标题就知道结论。例：“审核人员七成时间用于逐张核对规则”。
- 问题式：把听众的问题直接当标题。例：“现有系统的数据怎样迁移”。

默认写法由场景档给出，全稿保持一致。两条通用规则：

- 用主题式标题时，论点由导语承担。
- 用论断式标题时，过程页、定义页、总览页仍可用名词短语。这类页没有“发现”，硬写成论断会变成口号。

标题不超过两行，不用祈使句，不用“从 X 到 Y”这类套路句式，结尾不加句号。论断式标题里有数字时把数字写出来。

## 三、导语

导语不是每页必有，什么时候写见第一节。要写就写成一句有内容的话，标签式的导语等于没写。

| 标签式导语 | 改成 |
|---|---|
| 三个入口的判断条件 | 目标是否明确，决定从哪个入口开始 |
| 风险、原因和应对 | 三项风险里两项可以在试行中调整，一项只能如实说明 |
| 积压对业务部门的影响 | 月底集中提交造成积压，业务部门的报销平均晚到一周 |
| 本章回顾 | 直接写本章的收束句 |

论断式标题下的导语可以只写数据口径，例如“对 200 张单据的审核过程计时，按工作内容分类”。

## 四、主体

主体分成一到三个内容块，其中一个是主块，占页面的主要面积。其余是辅块，为主块服务：补一句说明、给一个例子、列出数据来源。

辅块多于两个，或者几个块同等重要，说明这页装了不止一个论点。

一页有两个以上内容块时，在 `layout` 里写这页的版式：单块、左主右辅、上主下辅、左右对照、上下两段、三栏，或“其他：……”。各版式的分法见 `layout.md` 第二节。

## 五、信息密度

密度由场景档给出，按页面类型微调：

- 低：一个论点加一个图示或一个数字。用于大场合和章首页。
- 中：论点、一个主图示、三到五处标注或说明。
- 中高和高：主图示内部带细节，例如分层架构里每层列出组成，流程每步写明输入、输出和负责人。用于会议室里讲、会后还要留档的材料。

密度高靠图示内部的结构承载，不靠增加文字块的数量。做法是每一项写成“名称：说明”，说明里放做法、数据或例子，例如“并行比对：系统与人工各审一遍，逐单比对结论”。只写名称的项，排到页面上只有一行字，页面会发空。中高密度的正文页，内容块里的文字一般在 100 字以上（初始建议值，图表页和截图页除外）；材料里确实没有更多内容的，与相邻页合并。界面展示页例外：截图是证据本身，要大，文字退到侧边标注。

## 六、讲述要点

现场讲的材料，可以在 `notes` 里写一两句讲法：从哪里讲起、哪一处停下来问听众、这页大约讲多久。给听众看的内容不写在这里。

材料会留给听众或发给对方时，`notes` 跟着文件走。这时不在里面写待定标记和只给讲者看的话，这类内容写在给用户的回复里。对外材料的 `notes` 同样不写对内信息。

## 七、页面角色

| role | 用途 |
|---|---|
| cover | 封面 |
| agenda | 提纲 |
| opener | 章首页或分隔页，承载本章的 `opens`；可以复用提纲或全景图并标出当前位置 |
| overview | 总览页：一页给出一组内容的全貌，后面的页逐个展开 |
| content | 正文页。摘要页也用 content，放在 `opening` 区 |
| summary | 小结页，承载本章的 `closes` |
| closing | 全稿收尾：总结、下一步、请求事项。练习、常见错误这类收尾内容用 content，放在 `closing` 区里 |
| appendix | 附录 |

## 八、这一层的自检

对每页问四件事：

- 遮住主体，只看标题和导语，知不知道这页要说什么。
- 遮住标题，只看主体，能不能得出标题里的那句话。
- 结论条说的是不是新东西。
- 这页删掉，本章的论点还成立吗。成立的话，它该进附录。
