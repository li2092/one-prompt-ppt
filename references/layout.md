# 版式：把大纲排到页面上

生成 pptx 的步骤见 `render.md`。这份文件管页面怎么分区、内容块怎么摆、字号下限和放不下时怎么办。每个内容块内部怎么画见 `components.md`。

用户给了模板时，模板优先：分区位置、字体、颜色、页脚都按模板，本文件里的数值只在模板没有规定时使用。数值均为初始建议值。

## 一、页面分区

正文页自上而下是：章节标签、标题、导语、主体区、结论条、出处和页码。这些固定位置由模板的版式决定，同一份材料里同类页的位置完全一致；位置和字号不在页面代码里另写。主体区的范围写在模板的风格文件里。

没有模板时用 skill 自带的模板，见 `render.md` 第一节。

## 二、主体区怎么分

按这页的内容块数量和主次选一种版式，写进大纲里该页的 `layout`。

| 版式 | 分法 | 适合 |
|---|---|---|
| 单块 | 主体区整块给一个图示 | 一个主图示就能说清的页；架构、流程、表格 |
| 左主右辅 | 左约 65% 放主块，右约 35% 放说明、例子或数据 | 图示需要旁注；截图加标注说明 |
| 上主下辅 | 上约 65% 放主块，下约 35% 放补充 | 流程在上，各步的输入输出或负责人在下 |
| 左右对照 | 左右各一半，结构相同 | 两个方案、前后状态 |
| 上下两段 | 上下各一半 | 先总后分：上面是总览，下面是展开 |
| 三栏 | 等宽三栏，结构相同 | 三个并列对象，每个都有内部结构 |

- 看一眼页面，最先看到的应该是主块。主块的大小跟着它的内容走：内容少就让它小，余下的地方留白，不拉大图示去填。
- 块与块之间留出明显的间隔，约为页面宽度的 2%。
- 不合适时写“其他：……”并说明分法。
- 连续几页版式相同是正常的，只要内容关系相同。不为了变化而换版式。

## 三、不同角色的页

| 角色 | 排法 |
|---|---|
| 封面 | 标题、副标题、单位、日期。不放正文内容 |
| 提纲 | 各章名称和一句话论点，按章的先后排列；在章首复用时标出当前章 |
| 章首页 | 章名、章首预告。内容少，留白多 |
| 总览页 | 单块版式，一个图示给出全貌；后面的展开页沿用图示里的名称、编号和颜色 |
| 正文页 | 按第二节 |
| 小结页 | 复用本章总览图并标出已讲部分，加一句收束 |
| 收尾页 | 总结或请求事项，条目少，字号可大一档 |
| 附录 | 版式与正文页相同，页码单独编或接续 |

## 四、字号

字号下限按“投影后坐在后排也看得清”来定。放不下时先按第六节处理，不往下限以下缩。

| 文字 | 中文 | 英文 |
|---|---|---|
| 页标题 | 20 到 24pt，加粗 | 22 到 26pt |
| 导语、结论条 | 13 到 14pt | 14pt |
| 块内小标题、组名 | 13 到 14pt，加粗 | 14 到 15pt |
| 正文、图示内的说明 | 不低于 12pt | 不低于 12pt，行距收紧到 1.0 到 1.1 |
| 表格单元格、架构图内的标签 | 不低于 10.5pt | 不低于 11pt |
| 出处、连线上的标签 | 9 到 10pt | 9 到 10pt |

- 全稿只用一到两种字体，用模板的主题字体。
- 密度为“低”的页，各级字号上调一到两档。
- 英文同字号看起来比中文小，行也更长。中文稿译成英文时重排，不沿用中文的字号和框。

## 五、对齐、间距和颜色

- 同一组里的同类元素大小相同、间距相等、边缘对齐。
- 文字左对齐。只有标题、卡片里的单个数字或短标签可以居中。
- 颜色用模板的主题色。一个主色，一到两个辅助色，一个强调色。强调色只用在要听众先看到的地方，一页不超过两处。
- 同一种颜色在全稿表示同一个意思。例如蓝色表示新建、灰色表示现有系统，就全稿如此。
- 不用标题下划线、页面边缘的色条、卡片单侧的色条。区分块用整圈细边框或浅底色。
- 不加与内容无关的装饰图形和图标。

## 六、放不下时的处理顺序

1. 压缩文字：删掉修饰语，句子改成短语，每项不超过两行。
2. 表格重新分配列宽，或换成更省地方的图示。
3. 把次要内容移到讲述要点或附录。
4. 拆成两页。拆页后回到大纲，补上新页的标题和导语。

不靠缩小字号和压缩行距来塞内容。截图是证据时，不缩小截图。

## 七、生成后的检查

把每页渲染成图片逐页看：

- 文字有没有溢出文本框或页面，有没有被遮挡。
- 同类页的标题、导语、结论条是否在同一位置。
- 元素之间、元素与页边之间的间隔是否均匀。
- 有没有低于字号下限的文字。
- 一个词或一个数字有没有被拆成两行。出现时调整框的宽度或改短文字，不往文字里插入不可见字符。
- 框太窄、12pt 的字要折成三行以上时，说明这个组件装不下这些内容：减少项数、改成上下排，或换组件。
- 模板里没用到的占位符是否已删除。
